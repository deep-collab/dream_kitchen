# Photo prompts for Dream Kitchen

Hema asked for realistic photos; AI-generated is fine. One prompt per product below. Each one is
complete: copy it as it is into the image tool, and paste the **negative prompt** into its
"negative prompt" / "avoid" box if it has one.

**Then:** save the picture named exactly as shown (for example `pista-bar.jpg`) into the
`photos-incoming` folder and run `node scripts/photos.mjs`. It makes the 1200px and 600px
versions and the site shows them at once. Until a photo exists, the site shows the gold drawing.

**Check every picture before using it.** It must look like what Hema actually makes. If her real
Delight Box or tub looks different (layers, toppings, box style), change the prompt or use a
real photo instead. **Pista must never look like Mango:** pista is pale pistachio green with
crushed green pistachios; mango is bright golden yellow.

**Negative prompt (use for every photo):**
`text, letters, words, logo, watermark, label, brand packaging, hands, fingers, people, cutlery covering the food, cartoon, illustration, 3D render, plastic look, oversaturated, blurry subject, duplicate items, cut-off product, busy background, flowers covering the product`

Shared look (already written into each prompt): realistic food photography, square 1:1, the product
fills about two thirds of the frame, dark slate or matte black surface, a few subtle gold accents
(a thin gold ribbon or a gold-rimmed edge in the background, never on the food), soft natural
light from the side, 45-degree angle unless stated, shallow depth of field, warm but true colours.
