# Training video: "Adding offers and editing products"

For Hema. About 3½ minutes, recorded on a phone screen (390 × 844) in the **practice admin**
(`/admin/demo`), so nothing real changes. Same style as the first walkthrough
(`scripts/walkthrough-video.mjs`): one caption per step, a calm voice reading the words in quotes,
a gold circle where the finger taps. Each part can also be sent on its own as a short clip.

| Part | On screen (what to tap) | Caption | Voice |
|---|---|---|---|
| **1. The new Offers button** (15 s) | Admin Home. Circle the bottom bar. | Home · Orders · **Offers** · Classes · Menu · More | "There is a new button at the bottom: Offers. It sits between Orders and Classes." |
| **2. Edit a name** (35 s) | Menu → Almond Bar → **Edit name** → type "Roasted Almond Bar" → Kannada name → **Save name**. | Edit name → Save name | "In Menu, every product now has Edit name, next to Save and Mark sold out. Type the new name in English, and in Kannada if you like. Tap Save name. The green line means it is on the website now. The product keeps its price, its photo and its old orders." |
| **3. A description** (30 s) | Pista Bar → **Description** → type a short sentence; circle the counter → **Save description**. | Up to 200 letters | "Description is the short text customers see when they tap the product. The counter shows how many letters you have used, up to two hundred. Tap Save description." |
| **4. Add a new product** (50 s) | Scroll to the end of **Brownies** → gold **+ Add new product** → name "Choco Chip Brownies", description, price 450, **Ragi version: Yes**, 60, **Small parcel**, choose a photo → **Add to menu**. | + Add new product, at the bottom of each section | "To add a product, go to the end of its section and tap Add new product. Write the name, a short description and the price. If it can be made with ragi, choose Yes and type the extra price. Choose the parcel size for the courier, add a photo if you have one, and tap Add to menu. It is on the website straight away. The website checks every price again for every order." |
| **5. Customize page photos** (25 s) | Menu → tap **Customize page** at the top → the "Delight Box with a name or a drawing" tile → **Change photo** → pick a photo → "Photo saved". | Customize page → Change photo | "The photos on the Customize page have their own Change photo buttons now. Pick a photo, wait for Photo saved, and it is on the website." |
| **6. Add an offer** (50 s) | **Offers** → circle the note → **+ Add new offer** → title "Diwali Delight Boxes", message, **Where the button goes: Menu: Delight Boxes**, start today, end Sunday → circle **How it looks on the website** → **Add offer** → the card says **Live**. | Offers show a banner. They do not change prices. | "Offers put a banner at the top of your website. They do not change prices: if your offer has a special price, change it in Menu. Tap Add new offer. Write a title and a short message, choose where the button goes, and pick the start and end dates. You can see how it will look. Tap Add offer. Live means it is on the website now." |
| **7. On the website** (20 s) | Open the website Home: the banner at the top, the dots; tap **See offer** → the Delight Boxes. | The banner on Home | "Here it is, at the top of the Home page, with Order now still in view. With two offers they take turns, and the dots pick one. Tapping goes where you chose." |
| **8. Schedule, turn off, delete** (30 s) | Add an offer starting next week → it says **Scheduled**. On the live one tap **Turn off** → **Off**. Tap **Delete** → "Yes, delete it". | Scheduled · Turn off · Delete | "An offer with a later start date says Scheduled: it starts by itself. After its end date it says Ended and leaves the website by itself. Turn off takes it away at once. Delete asks first, then removes it for good." |
| **End** (5 s) | Admin Home. | Practise any time at /admin/demo | "You can practise all of this in the demo admin. Nothing there is real." |

Recording notes:
- Use the demo admin; it already has sample offers in every state (Live, Scheduled, Off, Ended).
- For part 7, the website's banner shows only offers on the real (or practice) database, not the
  demo's samples. Record it from the practice database (`DK_DEV_DATA_DIR=.dev-data/video`) after
  adding one offer there, or use the screenshots in `docs/screenshots/offers/` (20-home-banner-*).
- Keep the voice "Zira" and the caption style of the first video, so the two feel like one set.
